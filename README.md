# TejaDev TypeScript Monorepo Template

This is a starter monorepo template created by **Teja**.

It uses:

- npm workspaces
- Turborepo
- TypeScript
- ESLint + Prettier
- Husky + lint-staged + Commitlint

## Structure

- `apps/` – application code (e.g. `web`, `api`)
- `packages/` – shared libraries and configs
- `.github/workflows/` – CI workflows
- `.husky/` – Git hooks (pre-commit, commit-msg)
- `.vscode/` – recommended editor settings
